# Digital Clock ⏲️

A digital clock simulation built in C.

## 📋 Features
- Has seperate files for Windows and Linux
- 24 hour clock

## 🛠️ How to Run
```bash
gcc digital-clock-default.c -o digital-clock-default
./digital-clock
```

## 📖 How to Use
1. Run the program
2. Clock starts running

## 💡 Concepts Used
- Loops and conditions
- Functions
- Multiple libraries

12:20:25
