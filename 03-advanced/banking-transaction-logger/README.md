# Banking Transaction Logger 🏦

A banking transaction logger built in C.

## 📋 Features
- Check account balance
- Deposit money
- Withdraw money
- Save to external file

## 🛠️ How to Run
```bash
gcc banking-transaction-logger.c -o banking-transaction-logger
./banking-transaction-logger
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options
3. Follow on-screen instructions

## 💡 Concepts Used
- Loops and conditions
- Functions
- User input validation
- Simple data management
- File handling
