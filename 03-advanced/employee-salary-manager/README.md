# Employee Salary Manager 👔

An employee salary manager that calculates highest, lowest, total and average salaries for a specific employee count.

## 📋 Features
- Gets user input for employee count
- Calculates total and average
- Calculates highest and lowest
- Calculates new salary after 10% bonus

## 🛠️ How to Run
```bash
gcc employee-salary-manager.c -o employee-salary-manager
./employee-salary-manager
```

## 📖 How to Use
1. Run the program
2. Enter number of employees
3. Enter salaries for each employee

## 💡 Concepts Used
- Loops and conditions
- Dynamic memory
- Multiple libraries
