# Inventory System 📦

An inventory system that stores, updates and saves products based on user input

## 📋 Features
- Gets user input for product count
- Adds new products
- Appends existing products
- Saves to file

## 🛠️ How to Run
```bash
gcc inventory-system.c -o inventory-system
./inventory-system
```

## 📖 How to Use
1. Run the program
2. Enter number of products
3. View menu and select choice
4. follow menu options

## 💡 Concepts Used
- Loops and conditions
- Dynamic memory
- Multiple libraries
- Functions
- Switch case
- Arrays
- File handling
- Structs
