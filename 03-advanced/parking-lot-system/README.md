# Parking Lot System 🅿️

A parking lot system that displays available and empty slots.

## 📋 Features
- Gets user input for which slot car should be parked in
- Gets user input for which slot car should be removed from
- Displays slot availability

## 🛠️ How to Run
```bash
gcc parking-lot-system.c -o parking-lot-system
./parking-lot-system
```

## 📖 How to Use
1. Run the program
2. Enter choice
3. Follow menu instrustions

## 💡 Concepts Used
- Loops and conditions
- Switch case scenarios
- Arrays
