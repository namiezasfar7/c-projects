# Student Record Management System 👨‍🎓

A student record management system that manages student data.

## 📋 Features
- Gets user input for number of students
- Gets user input for each student
- Displays total, average and grade
- Saves to file

## 🛠️ How to Run
```bash
gcc student-record-management-system.c -o student-record-management-system
./student-record-management-system
```

## 📖 How to Use
1. Run the program
2. Enter number of students
3. Follow menu instrustions

## 💡 Concepts Used
- Loops and conditions
- Dynamic memory
- Structs
- Functions
- Arrays
- File Handling
