# Hospital Patient Manager 🏥

A hospital patient manager that calculates min, max, total and average number patients for a specific day count.

## 📋 Features
- Gets user input for day count
- Calculates total and average
- Calculates min and max

## 🛠️ How to Run
```bash
gcc hospital-patient-manager.c -o hospital-patient-manager
./hospital-patient-manager
```

## 📖 How to Use
1. Run the program
2. Enter number of days
3. Enter paients for each day

## 💡 Concepts Used
- Loops and conditions
- Dynamic memory
- Multiple libraries
