# Number Guessing Game v2 🔢

User guesses a random number generated in C.

## 📋 Features
- Numbers changes everytime
- Has 3 difficulties
- Tracks number of tries

## 🛠️ How to Run
```bash
gcc number-guessing-game-v2.c -o number-guessing-game-v2
./number-guessing-game-v2
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options
3. Follow on-screen instructions

## 💡 Concepts Used
- Loops and conditions
- Switch case scenarios
- pseudo-numbers formula
- User input validation

## 📸 Sample Output
---NUMBER GUESSING GAME---

1. Easy (1 - 10)
2. Medium (1 - 50)
3. Hard (1 - 100)
4. Exit
