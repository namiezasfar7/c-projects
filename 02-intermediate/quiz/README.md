# Quiz ❓

User answers MCQ style questions and scores points.

## 📋 Features
- Has 4 questions
- Tracks score
- Simple logic

## 🛠️ How to Run
```bash
gcc quiz.c -o quiz
./quiz
```

## 📖 How to Use
1. Run the program
3. Choose from the menu options
4. Follow on-screen instructions

## 💡 Concepts Used
- Loops and conditions
- Arrays of strings
- User input validation
