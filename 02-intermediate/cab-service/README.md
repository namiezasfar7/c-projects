# Cab Service 🚕

Takes inputs for a cab package and prints total bill.

## 📋 Features
- Takes package type
- Takes payment method
- Takes distance

## 🛠️ How to Run
```bash
gcc cab-service.c -o cab-service
./cab-service
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options
3. Enter package type
4. Choose from the menu options
5. Enter payment method
6. Enter distance

## 💡 Concepts Used
- Conditions
- Functions
- Switch case scenarios
- Breaks and continues
- User input validation
