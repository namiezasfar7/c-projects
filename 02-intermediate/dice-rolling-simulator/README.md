# Dice Rolling Simulator 🎲

Rolls a random number 1 - 6.

## 📋 Features
- Has menu screen
- Simple logic

## 🛠️ How to Run
```bash
gcc dice-rolling-simulator.c -o dice-rolling-simulator
./dice-rolling-simulator
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options
3. Follow on-screen instructions

## 💡 Concepts Used
- Conditions
- Pseudo-numbers
- Breaks
- User input validation

## 📸 Sample Output
----DICE ROLLING SIM---

1. Roll Dice
2. Exit
