# Election Vote Counter 💯

An vote counter machine simulated in C.

## 📋 Features
- Finds winner
- Shows winner percentage
- Saves information to external file
- Reads information from external file

## 🛠️ How to Run
```bash
gcc election-vote-counter.c -o election-vote-counter
./election-vote-counter
```

## 📖 How to Use
1. Run the program
2. Vote desired candidate

## 💡 Concepts Used
- Conditions
- Functions
- User input validation
- Arrays
- File handling
