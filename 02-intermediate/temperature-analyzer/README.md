# Temperature Analyzer 🌡️

Finds highest, lowest and average of temperatures of a week.

## 📋 Features
- Find highest, lowest and average of temperatures
- Saves to external file

## 🛠️ How to Run
```bash
gcc temperature-analyzer.c -o temperature-analyzer
./temperature-analyzer
```

## 📖 How to Use
1. Run the program
2. Enter temperatures

## 💡 Concepts Used
- Conditions
- Arrays
- File handling
- Functions
- Pointers
