# Rock Paper Scissors Game 🎮

Rock paper scissors game simulated in C.

## 📋 Features
- 3 choices
- Simple logic

## 🛠️ How to Run
```bash
gcc rock-paper-scissors-game.c -o rock-paper-scissors-game
./rock-paper-scissors-game
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options

## 💡 Concepts Used
- Loops and conditions
- Arrays of strings
- Pseudo numbers
- User input validation
