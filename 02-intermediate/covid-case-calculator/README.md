# Covid Case Calculator 🧮

Takes inputs for covid cases and calculates total, min, max and average.

## 📋 Features
- Takes 12 inputs
- Simple logic

## 🛠️ How to Run
```bash
gcc covid-case-calculator.c -o covid-case-calculator
./covid-case-calculator
```

## 📖 How to Use
1. Run the program
2. Enter number of cases for each month

## 💡 Concepts Used
- Conditions
- String header file
- 2D arrays
