# Library Book Counter 📚

A library management simulated in C.

## 📋 Features
- Has menu screen
- Saves information to external file
- Finds total amount of books

## 🛠️ How to Run
```bash
gcc library-book-counter.c -o library-book-counter
./library-book-counter
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options
3. Follow on-screen instructions

## 💡 Concepts Used
- Conditions
- Functions
- Breaks
- User input validation
- Arrays
- File handling
