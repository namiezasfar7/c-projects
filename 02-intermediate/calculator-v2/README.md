# Calculator v2 🧮

Takes inputs and calculates answer.

## 📋 Features
- Takes 2 inputs
- Uses menu
- Simple logic

## 🛠️ How to Run
```bash
gcc calculator-v2.c -o calculator-v2
./calculator-v2
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options
3. Enter numbers

- Functions
- Switch case scenarios
- Breaks and continues
- User input validation
