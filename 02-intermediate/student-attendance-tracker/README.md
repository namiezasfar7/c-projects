# Student Attendance Tracker 👨‍🎓

Finds attendance percentage.

## 📋 Features
- Takes user defined inputs
- Find attendance percentage

## 🛠️ How to Run
```bash
gcc studnet-attendance-tracker.c -o studnet-attendance-tracker
./studnet-attendance-tracker
```

## 📖 How to Use
1. Run the program
2. Enter student count
3. Enter students present or absent
