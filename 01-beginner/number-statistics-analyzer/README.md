# Number Statistics Analyzer 🔢

Categorizes 10 numbers into largest and smallest, finds total and average.

## 📋 Features
- Gets 10 inputs
- Finds largest
- Finds smallest
- Finds total and average
- Simple logic

## 🛠️ How to Run
```bash
gcc number-statistics-analyzer.c -o number-statistics-analyzer
./number-statistics-analyzer
```

## 📖 How to Use
1. Run the program
2. Enter numbers

## 💡 Concepts Used
- Loops and conditions
- Arrays
- Accumalators
