# Multiplication Table Generator ⌛

A multiplication table generator written in C.

## 📋 Features
- Gets user input
- Multiplies and displays products from 1 to 15

## 🛠️ How to Run
```bash
gcc multiplication-table-generator.c -o multiplication-table-generator
./multiplication-table-generator
```

## 📖 How to Use
1. Run the program
2. Enter number

## 💡 Concepts Used
- Loops and conditions
- Functions
- Function prototypes
