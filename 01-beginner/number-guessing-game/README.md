# Number Guessing Game 🔢

User guesses a random number generated in C.

## 📋 Features
- Numbers change everytime
- Tracks number of tries
- Simple logic

## 🛠️ How to Run
```bash
gcc number-guessing-game.c -o number-guessing-game
./number-guessing-game
```

## 📖 How to Use
1. Run the program
3. Choose from the menu options
4. Follow on-screen instructions

## 💡 Concepts Used
- Loops and conditions
- pseudo-numbers formula
- User input validation
