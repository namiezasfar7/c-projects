# Student Grade Calculator 🧮

Calculates students average and grade.

## 📋 Features
- Displays total
- Displays average
- Displays grade

## 🛠️ How to Run
```bash
gcc student-grade-calculator.c -o student-grade-calculator
./student-grade-calculator
```

## 📖 How to Use
1. Run the program
2. Enter student name
3. Enter student marks

## 💡 Concepts Used
- Conditions
- Arrays
- Loops
- User input validation
