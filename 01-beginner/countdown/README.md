# Countdown ⌛

A Countdown timer written in C.

## 📋 Features
- Counts down values from user input

## 🛠️ How to Run
```bash
gcc countdown.c -o countdown
./countdown
```

## 📖 How to Use
1. Run the program
3. Choose from the menu options
4. Follow on-screen instructions

## 💡 Concepts Used
- Loops and conditions
- User input validation

## 📸 Sample Output
5   4   3   2   1
