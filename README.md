# ⚙️ C Programming Projects

A curated collection of C programming projects built while learning C, progressing from beginner to advanced concepts. This repository documents my journey in mastering procedural programming, problem-solving, memory management, and systems programming through hands-on console applications.

---

## 📋 Repository Overview

This repository contains C projects categorized by difficulty level:

- 🟢 **Beginner** – Core C fundamentals and introductory console applications
- 🟡 **Intermediate** – Functions, arrays, strings, pointers, and more complex programming concepts
- 🟠 **Advanced** – Larger applications utilizing dynamic memory allocation, file handling, and modular programming

Each project includes its own source code and a dedicated **README.md** explaining its features, usage, and learning objectives.

## ▶️ How to Compile and Run

1. Install the latest **GCC Compiler**.
2. Navigate to the desired project directory.

### Compile

```bash
gcc main.c -o output
```

### Run

```bash
./output
```

> **Note:** Some projects may use a different project name. Refer to the project's individual `README.md` for project-specific instructions.
